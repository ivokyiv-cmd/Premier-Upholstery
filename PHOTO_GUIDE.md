# Photo Guide — Premier Leather & Upholstery
## Exact filenames, folder locations, alt text, and crop instructions

---

## HOW TO ADD PHOTOS

1. Crop each photo into individual BEFORE and AFTER files (see crop instructions below)
2. Resize to max 1800px wide (any wider wastes load time; Next.js handles WebP conversion)
3. Save as JPG at 80–85% quality
4. Name the file exactly as shown in each table row below
5. Drop it into the correct folder inside `public/images/`
6. The website will automatically use it — no code changes needed

---

## CROP INSTRUCTIONS FOR EACH PHOTO

Each of your photos was sent as a combined image (stacked top/bottom or side-by-side).
You need to crop each one into TWO separate files.

| Terra cotta sectional | **Stacked** (before top, after bottom) | Crop top half → before; bottom half → after |

## ADDING NEW PROJECTS (future)

To add a new project after launch:

1. Drop before + after photos into the correct `public/images/projects/[category]/` folder
2. Open `src/data/services.ts`
3. Find the service you want to add it to
4. Add a new object to the `projects: []` array:

```typescript
{
  id: 'unique-id',
  title: 'Project Title',
  location: 'City, ST',     // optional
  before: {
    src: '/images/projects/[folder]/filename-before.jpg',
    alt: 'Descriptive SEO alt text — before state',
    caption: 'Short before label',
  },
  after: {
    src: '/images/projects/[folder]/filename-after.jpg',
    alt: 'Descriptive SEO alt text — after state',
    caption: 'Short after label',
  },
  description: 'One paragraph description of the project.',
  servicesPerformed: [
    'Service one',
    'Service two',
  ],
},
```

New projects automatically appear on:
- The service page (as a before/after slider)
- The gallery page
- The home page (first 4 projects shown)

No other code changes needed.
